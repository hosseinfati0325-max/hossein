# حسین و فاطمه (Hossein & Fatemeh)

سامانه جامع و هوشمند آموزش زبان‌های خارجی با پشتیبانی از هوش مصنوعی، یادگیری تطبیقی بر پایه الگوریتم جعبه لایتنر (SM-2)، ۵۲ هفته برنامه آموزشی مدون از سطح A1 تا C2، قابلیت کارکرد آفلاین (PWA و اندروید)، و آزمون‌های شبیه‌ساز بین‌المللی.

## ویژگی‌های کلیدی
- **هسته هوش مصنوعی**: دستیار صوتی و متنی، بررسی گرامر، دیالوگ‌های شبیه‌سازی‌شده و سنجش مهارت با مدل Gemini 2.5 Flash / 3.8 Flash.
- **معماری ماژولار**: کلاینت وب PWA (React + Tailwind CSS + Capacitor) و بک‌اند مقیاس‌پذیر (FastAPI + SQLAlchemy Async + Redis).
- **قابلیت استفاده آفلاین**: ذخیره‌سازی محلی پیشرفت و همگام‌سازی دوطرفه خودکار پس از اتصال مجدد به اینترنت.
- **آزمون‌های جامع و Mock Exam**: شبیه‌سازی آزمون‌های رسمی مانند IELTS، TOEFL، Goethe و DELF به همراه کارنامه تحلیلی هوشمند نقاط قوت و ضعف.
- **چندکاربره و ظرفیت واقعی**: ثبت‌نام و تفکیک پروفایل زبان‌آموزان با رهگیری مستقل سطح، امتیاز، الماس و زنجیره مطالعه (Streak).
